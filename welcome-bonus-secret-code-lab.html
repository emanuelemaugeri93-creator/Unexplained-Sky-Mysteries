How to use Secret Code Lab

Make cipher puzzle pages for kids' mystery books, worksheets and printables.

1
Pick your book settingsOn the left choose page size (US Letter, A4, square, 6×9, 8×10), print quality, margins and ink colour. Black & white is ink-friendly for printed books.
2
Auto-build or add pagesClick "Auto-build" to create a whole pack with rising difficulty, or add pages one by one: Secret Message, Decoder Key, Cipher Wheel, Create Your Own Code and Code Breaker's Toolkit.
3
Edit any pageChoose the cipher, difficulty, secret number, title, mission briefing, message and spy hint. The hint can be written for you. The preview updates instantly.
4
Use the LibraryBrowse ready-made sky-mystery messages, briefings and case titles and drop them into your pages with one click.
5
ExportDownload one PDF with every page, a ZIP of PNG images (great for Canva or other editors), or a single page as PNG. An answer key page is added at the end automatically.
Tips: Put a Decoder Key card before the first puzzle that uses a new cipher. Keep early messages short. For printed books export at 300 dpi. Use the Quick Encoder to test a message, and the Code Breaker to double-check any puzzle you write.
