Generation Mode

HOW MANY PAGES?
You decide the page count, not the number of parsed cases. Rotate mode = roughly 1 page per checked case (recommended for the book itself). Full Grid = every checked case × every checked activity type (use only for a bigger bonus pack). The live total below always shows exactly what will compile — check it before clicking Compile Activity Pages.
Rotate cycles through your checked activity types case by case, so a 60-case book makes ~60 pages, not 60 × (number of types). Full Grid makes every combination — pick this only when you deliberately want a bigger set.
Enter how many pages you actually want in the finished book, then click Auto-fit — it trims your case selection (keeping the first N checked cases) so the compiled total lands at or just under your target, given the current mode and checked activity types/bookends.
